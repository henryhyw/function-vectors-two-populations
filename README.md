## One-shot reproduction

```bash
# 1. environment
pip install torch transformer_lens transformers numpy scipy matplotlib

# 2. run the pipeline (will overwrite ./results/)
jupyter nbconvert --to notebook --execute pipeline.ipynb --inplace
```

Single A100 wall-clock ≈ 18 hours; discovery + path-patching dominates, and the 6.9B / 12B Pythia sizes account for most of the runtime.

The `results/` directory in this release is the seeded output of one such run; you can skip step 2 and inspect it directly, or re-run to regenerate it from the pretrained models.

## Results layout

Each per-cell experiment writes to `results/{task}/F0/{stage}/`, where `F0` is the frozen prompt format used throughout the paper. The four stages are `discover/`, `validate/`, `mechanism/`, `controls/`. Auxiliary experiments (sign-shuffle, vocab transfer, case study, scale extension, etc.) land in `results/_aux/<theme>/`. See `results/_aux/README.md` for a per-theme inventory.

The single source of truth for paper-cited numbers is `extracted_numbers.json`, keyed by claim location. It is regenerated by `code/aggregate.py` at the end of `pipeline.ipynb`.

## Scope of the package

The pipeline reproduces:

- the 13/15-cell W/C verdict (Pythia 410M–12B, Qwen2.5-{1.5, 7}B, GPT-2-medium);
- the six population-level mechanism rule-outs on the 27 canceller (cell, head) pairs across the six main cells;
- the L11.H4 case study (V-shuffle, OV spectrum, V-composition);
- the vocabulary-ICL cross-template transfer (antonym, country-capital);
- the scale + cross-architecture extension cells;
- the canceller-ablation accuracy effect (+2 to +7 pp directionally, CI-confirmed on hier-410M).

Additive-steering vectors are constructed (`code/steering.py`) and evaluated under held-out $\alpha$ on logit shift (paper App. D.1); the paper makes no positive accuracy claim from additive steering, and the earlier in-sample-$\alpha$ evaluation path is explicitly excluded as confounded.
